# Website Profil Zuhrotul Mafazati

## Cara memasang di GitHub Pages
1. Ekstrak file ZIP ini.
2. Buat repository baru di GitHub, misalnya `profil-pribadi`.
3. Unggah file `index.html` ke bagian utama (root) repository.
4. Buka **Settings → Pages**.
5. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
7. Tunggu beberapa saat. GitHub akan menampilkan alamat website kamu di bagian Pages.

## Catatan privasi
Website ini menampilkan domisili secara umum saja. Nomor HP dan alamat rumah lengkap tidak dicantumkan karena website GitHub Pages dapat dilihat oleh siapa saja. Email pada contoh ditulis sebagai `zatimafa70@gmail.com`; periksa kembali apakah alamat email tersebut benar sebelum dipublikasikan.

## Mengubah galeri
Edit bagian `id="galeri"` pada `index.html`. Kamu bisa menambahkan gambar dengan tag:
`<img src="images/nama-foto.jpg" alt="Deskripsi karya">`
Buat folder `images` di repository dan unggah foto karya milikmu.
